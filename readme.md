# Programación III

## Autor

## Descripción

Repositorio académico de la materia **Programación III**, donde se desarrollarán prácticas, ejercicios y proyectos relacionados con el desarrollo web frontend y backend.

## Tecnologías y conceptos

### HTML

Lenguaje de marcado utilizado para estructurar el contenido de las páginas web mediante elementos como títulos, párrafos, imágenes, enlaces y formularios.

### CSS

Lenguaje de estilos que permite diseñar y personalizar la apariencia de las páginas web, incluyendo colores, tamaños, distribuciones y diseños adaptables.

### JavaScript

Lenguaje de programación que permite agregar interactividad y funcionalidades dinámicas a las páginas web.

### TypeScript

Lenguaje basado en JavaScript que incorpora tipado estático y otras herramientas para desarrollar aplicaciones más organizadas y fáciles de mantener.

### NestJS

Framework de Node.js basado en TypeScript que permite desarrollar aplicaciones backend y API utilizando una arquitectura modular.

### ReactJS

Biblioteca de JavaScript utilizada para construir interfaces de usuario mediante componentes reutilizables.

## Objetivos

* Aprender los fundamentos del desarrollo web.
* Crear interfaces dinámicas e interactivas.
* Desarrollar aplicaciones frontend y backend.
* Comprender el uso de frameworks y bibliotecas modernas.
* Aplicar los conocimientos adquiridos en ejercicios y proyectos prácticos.
